ความคืบหน้า: 0/10 ข้อ
01
ตอบสั้น
การวิเคราะห์งานก่อนเขียนโปรแกรมประกอบด้วย 5 ขั้นตอนอะไรบ้าง?
02
ถูก–ผิด
“ผังงานช่วยให้เห็นลำดับขั้นตอนการทำงาน ตรวจสอบข้อผิดพลาด และแก้ไขงานได้ง่ายขึ้น”
03
จับคู่
จับคู่สัญลักษณ์กับหน้าที่ให้ถูกต้อง
เริ่มต้น / สิ้นสุด
ตรวจสอบเงื่อนไข
คำนวณหรือประมวลผล
รับข้อมูลหรือแสดงผล
04
เลือกตอบ
ถ้าต้องตรวจสอบว่า “คะแนน ≥ 50” หรือไม่ ควรใช้สัญลักษณ์ใด?
05
เลือกตอบ
ขั้นตอน total = price × amount ควรใช้สัญลักษณ์ใด?
06
ถูก–ผิด
“ผังงานที่ดีสามารถมีจุดเริ่มต้นหลายจุดได้ หากโปรแกรมมีขั้นตอนจำนวนมาก”
07
จับผิดผังงาน
กำหนดลำดับ START → DISPLAY sum → INPUT num1,num2 → sum=num1+num2 → STOP ลำดับนี้ผิดอย่างไร และควรเรียงใหม่อย่างไร?
08
วิเคราะห์สถานการณ์
โปรแกรมรับ base และ high เพื่อคำนวณพื้นที่สามเหลี่ยม จงระบุ Input / Process / Output
09
คิดวิเคราะห์
ถ้าผังงานมีลูกศรหลายเส้นตัดกันจนอ่านยาก นักเรียนควรแก้ไขอย่างไร? เพราะเหตุใด?
10
ปฏิบัติ
ร้านค้าต้องการโปรแกรม รับราคาสินค้าและจำนวนสินค้า → คำนวณราคารวม → แสดงราคารวม ให้วิเคราะห์ Input–Process–Output แล้วเขียนลำดับ Flowchart
